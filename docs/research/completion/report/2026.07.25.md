### 2.1 `submodules/helixtrack-core/Website/Upstreamable` — missing submodule URL (BLOCKER)

- **Evidence:**
  ```text
  fatal: No url found for submodule path 'submodules/helixtrack-core/Website/Upstreamable/Upstreamable' in .gitmodules
  fatal: Failed to recurse into submodule path 'submodules/helixtrack-core/Website/Upstreamable'
  fatal: Failed to recurse into submodule path 'submodules/helixtrack-core/Website'
  fatal: Failed to recurse into submodule path 'submodules/helixtrack-core'
  ```
- **Root cause:** A nested submodule inside `submodules/helixtrack-core/Website/Upstreamable` is declared in the helixtrack-core `.gitmodules` but has no URL entry, so recursive initialization fails.
- **Impact:** The `helixtrack-core` submodule cannot be reliably cloned/updated with `--recursive`.
- **Action:** Add the missing nested submodule URL to `submodules/helixtrack-core/.gitmodules` (or remove the orphan submodule if it is not needed), then re-run `git submodule update --init --recursive`.
